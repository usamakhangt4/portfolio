## Problem

Global Foods needs a customer application, an EPOS, and an operations application, with Android and iOS builds and a shared backend.

## Contribution

My work included EPOS VAT, payments, and push notifications, across the Laravel backend and the Vue applications.

## Architecture

The backend is Laravel with MariaDB. Reverb provides WebSockets. Queue workers handle background work. Docker packages the backend environment.

Three Vue and Vite applications cover customer, EPOS, and operations. Ionic and Capacitor produce the Android and iOS builds.

## Technical decisions

Customer, EPOS, and operations are separate Vue and Vite applications on the shared Laravel and MariaDB backend. Realtime updates use Reverb. Background work uses queue workers. Mobile builds go through Ionic and Capacitor. EPOS behavior I worked on includes VAT, payments, and push notifications.
